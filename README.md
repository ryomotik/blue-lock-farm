# ⚽ [🎃] Ферма синих замков (Blue Lock Tycoon) — AutoFarm

Автоматический скрипт-фармер для игры **«[🎃] Ферма синих замков»** (Blue Lock Tycoon) в Roblox с современным интерфейсом на базе библиотеки **Fluent**.

---

## 🌟 Основные возможности

- **💰 Авто-сбор и продажа**:
  - Автоматически забирает ящики с мячами с ленты тайкуна (`CollectPart`).
  - Относит их скупщику (`sell npc`) и мгновенно продает.
  - Собирает и продает хэллоуинские мешки с конфетами (`CandyPart`).
- **📦 Авто-открытие шкафчиков**:
  - Отслеживает таймеры открытия шкафчиков на дропперах.
  - Моментально открывает готовые шкафчики и экипирует сильнейших юнитов (`EquipBestPlayerUnits`).
- **🎲 Авто-крутка и расстановка**:
  - Автоматически крутит новые шкафчики на конвейере по кулдауну.
  - Покупает их и устанавливает на пустые дропперы.
- **📈 Авто-прокачка (Upgrades)**:
  - Автоматическая покупка улучшений тайкуна при наличии денег:
    - Множитель денег за ящики (*Crate Cash Boost*)
    - Увеличение удачи (*Luck Boost*)
    - Тир конвейера (*Conveyor Luck Tier*)
    - Ускорение времени открытия шкафчиков (*Open Time Boost*)
    - Расширение базы / новые слоты (*Base Expansion*)
    - Скорость бега персонажа (*Walk Speed*)
- **🎁 Авто-забор всех наград**:
  - Ежедневный бонус за вход
  - Награды за время в игре (1–12 слотов)
  - Награды индекса и оффлайн-прибыли
  - Бонусы за победу в Obby (Easy, Medium, Hard)
- **🛡️ Anti-AFK**:
  - Защита от стандартного 20-минутного отключения Roblox за бездействие.

Запустите скрипт через любой современный экзекутор (Real, Solara, Wave, Synapse и др.):

```lua

```


## ⌨️ Управление интерфейсом

- **Right Control (Правый Ctrl)** — свернуть / развернуть меню Fluent.
- Вкладки разделены по категориям:
  - **Фарм / Main**: Основные переключатели авто-сбора и продажи.
  - **Шкафчики / Lockers**: Управление открытием, круткой и установкой шкафчиков.
  - **Прокачка / Upgrades**: Выбор улучшений для автоматической прокачки.
  - **Награды / Rewards**: Автоматический и ручной сбор всех видов наград.
  - **Настройки**: Anti-AFK и кнопка безопасной остановки скрипта.
