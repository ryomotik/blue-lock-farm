## ⌨️ Горячие клавиши и управление

- **Right Control (Правый Ctrl)** — Скрыть / показать главное меню Fluent.
- Вкладки интерфейса:
  - 🏠 **Главная**: Включение авто-сбора, продажи, авто-крутки и установки шкафчиков.
  - 📦 **Шкафчики**: Управление слотами, таймерами и выбор лучших юнитов.
  - ⚡ **10X Бусты**: Спидхак, ноуклип, сбор конфет, мировых дропов и Instant Prompts.
  - 📈 **Прокачка**: Настройка автоматических покупок улучшений тайкуна.
  - 🎁 **Награды**: Сбор ежедневных, временных и паркур-наград.
  - ⚙️ **Настройки**: Anti-AFK, Potato Mode, Discord Webhook и кнопка аварийной остановки.
